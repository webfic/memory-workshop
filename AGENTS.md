# Memory Workshop Authoring Scope

- For story-authoring requests in this workspace, create or edit only `background/*.card`, `character/*.card`, and `scene/*.txt`.
- Do not create or edit `draft/`, `.draft/`, `.storyboard/`, evaluation files, or other project files unless the user explicitly requests that specific scope.
- The user reviews the background, character, and scene sources and runs draft generation separately. Do not generate drafts unless explicitly asked.
